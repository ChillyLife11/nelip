# Nelip — мини-аппа клиники доктора Нелип

Мессенджер-мини-аппа (MAX) для онлайн-записи в клинику: запись на приём
(филиал → услуга → врач → дата/время), текущие и прошедшие визиты, акции,
обратная связь.

Проект развёрнут из [medix](../medix) — того же приложения для другой клиники.
Логика и структура общие, различается компания и оформление.

## Разработка

```bash
pnpm install
pnpm dev        # http://localhost:5175
pnpm build
pnpm preview
pnpm format     # prettier
```

Настройки окружения — в `.env` (пример: `.env.example`):

| Переменная         | Значение                     | Зачем                                              |
|--------------------|------------------------------|----------------------------------------------------|
| `VITE_API_HOST`    | `https://medix.amgs.online`   | бэкенд: dev-прокси `/api`, картинки, база сборки    |
| `VITE_COMPANY_ID`  | `4`                          | клиника: `company_id` в запросах и подпапка сборки  |
| `VITE_ASSET_HOST`  | —                            | хост раздачи сборки, если он не совпадает с API     |
| `VITE_BASE`        | —                            | перебивает базу сборки целиком                      |

Подробности по архитектуре, API и принятым решениям — в [CLAUDE.md](CLAUDE.md).
